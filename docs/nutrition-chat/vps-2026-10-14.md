- Kiểm trực tiếp thấy Supabase default grants cấp anon/authenticated vào bảng public. Bổ sung migration `20261014213000_nutrition_chat_private_access`: RLS + revoke PUBLIC/anon/authenticated cho rations và 4 bảng OAuth/hạn mức; app dùng role owner/BYPASSRLS nên hoạt động giữ nguyên.
- Sau áp, cả 5 bảng có RLS và anon/authenticated SELECT false. OAuth/PGlite 239 checks gồm 133 ACL/RLS mới; storage 82 và HTTP 77 đạt.
- **Ngoài phạm vi còn phải rà:** app_users và các bảng riêng cũ khác. Live check xác nhận app_users chưa bật RLS, anon/authenticated có SELECT; chưa kiểm cấu hình expose Data API hoặc thực hiện HTTP đọc bảng đó. Không tuyên bố đã harden toàn Supabase. Rà cấu hình/grants/RLS trước mở rộng sử dụng thực tế.
- Nguồn: [Supabase RLS và grants](https://supabase.com/docs/guides/database/postgres/row-level-security), [hardening Data API](https://supabase.com/docs/guides/api/securing-your-api).
